# Release history

## Version 2.3.0

Released on 18 November 2026.

- Added `supplementary_data/` with the three supplementary data files of manuscript version 1.13 (`Supplementary-Data-1-v1.13.zip`, `Supplementary-Data-2-v1.13.zip`, `Supplementary-Data-3-v1.13.zip`), their SHA-256 list and a description. They hold the S1/W5 control and the three additional sensitivity analyses, which were run after release v2.2.0, and the records of Experiments 1–3 in the form named by the manuscript.
- Updated the release description, citation metadata and Zenodo metadata to version 2.3.0, and refreshed the hashes of the root checksum manifest for the edited metadata files.

The scientific code, dependency specifications, retained result archives and verification commands are unchanged from release v2.2.0.

## Version 2.1.0

Released on 11 October 2026.

- Updated the accompanying study title and identified manuscript V4.4 as submitted to the Journal of Neuroscience Methods on 2 October 2026.
- Added individual dataset descriptions, source publications, licensor credit and upstream license information.
- Distinguished MIT software, CC BY 4.0 original documentation and generated results, and source dataset content that retains CC BY-ND 4.0 terms.
- Updated citation metadata and added metadata for archiving the software and retained results on Zenodo.
- Included the official CC BY 4.0 legal text and regenerated the release checksum manifest.

The scientific code, dependency specifications, optional CSP reference and stored numerical result archive are unchanged from the public v2.0 package at commit `63286819027270c790a626d36f29b6ae121570ae`. The release adds documentation and licensing information; it does not report new training experiments.

## Version 2.0

The existing public package contains preparation, training, analysis and verification code for the two completed experiments and the CSP–LDA reference, together with retained numerical results and EEGNet predictions.
